# 6T SRAM Cell – Design and Simulation

## Project Overview
This project focuses on the design and preliminary simulation of a 6T Static Random Access Memory (SRAM) cell using Qucs-S.

## Objectives
- To understand the basic operation of a 6T SRAM cell.
- To design the circuit using 2 PMOS and 4 NMOS transistors.
- To perform transient simulation using Qucs-S.
- To observe the voltage waveforms.

## Tools Used
- Qucs-S 26.1.1
- NGSpice Simulator

## Circuit Description
The 6T SRAM cell consists of:
- 2 PMOS transistors
- 4 NMOS transistors
- Cross-coupled CMOS inverters
- Bit Lines: BL and BLBAR
- Word Line: WL
- Storage Nodes: Q and QBAR

## Simulation Parameters
- Supply Voltage: 1.8 V
- Start Time: 0 s
- Stop Time: 1 ms

## Project Files
- Circuit schematic
- Simulation waveform
- Project report

## Result
The 6T SRAM circuit schematic was created in Qucs-S, and a preliminary transient waveform was obtained.

**Note:** Complete hold, read and write operation verification is pending.
